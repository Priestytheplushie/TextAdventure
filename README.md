# TextAdventure
A basic terminal text adventure game written in C#

## Prerequisites
* [.NET SDK](https://dotnet.microsoft.com/download)

## How to play 

```bash
dotnet run

```

## How to Play

* Follow the on-screen prompts.
* Enter the number corresponding to your choice and press **Enter**.
* Make smart decisions to survive the forest and defeat the beast!
